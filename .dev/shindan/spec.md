## 2. サマリーの監査（3分類）

### 確定仕様（そのまま採用）
- 8問・5タイプ（A〜E）、合計点で判定、同点時はQ1優先という考え方
- 1画面1問、進捗表示、結果ページでタイプ・最初に作るもの・計画・プロンプト・LINE・共有
- バックエンドなし、回答をブラウザ内で完結、`/shindan/` に配置

## 3. 診断ロジック（確定版）

### 設問と配点
| 問 | 種類 | 選択肢 → 加点 |
|---|---|---|
| Q1 いちばん楽にしたいこと | 分野 | 生活の面倒 A3 ／ 調べもの B3 ／ 仕事の作業 C3 ／ 発信・副業 D3 ／ まだぼんやり E3 |
| Q2 AI経験 | 準備度 | ほぼ無い E2 ／ 会話のみ E1 ／ 文章・表を作らせた 0 ／ ツールを作った 0 |
| Q3 週の時間 | 準備度 | 1時間未満 E2 ／ 1〜3時間 E1 ／ 3時間以上 0 |
| Q4 面倒なこと | 分野 | 家計・予定 A2 ／ 調べたことが散らばる B2 ／ 仕事の進み具合 C2 ／ 投稿・文章 D2 ／ 思いつかない E2 |
| Q5 作りたいもの | 分野 | 家族の管理ツール A2 ／ 情報をためて探す B2 ／ 仕事の管理表 C2 ／ 下書きの道具 D2 ／ 未定 E2 |
| Q6 パソコン操作 | 準備度 | 苦手・スマホ中心 E2 ／ ふつう 0 ／ 得意 0 |
| Q7 最初の1作 | 準備度 | 1日で動く小さなもの E2 ／ 1週間かけてしっかり 0 |
| Q8 使う場面 | 分野 | 家 A2 ／ 調べもの・勉強 B2 ／ 仕事 C2 ／ SNS・副業 D2 |

### 判定
1. タイプごとに合計し、最高点のタイプ
2. 同点なら **Q1で選んだタイプ → E** の順。配点の構造上、同点には必ずQ1のタイプかEが含まれる（全通りテストで確認）ので、これで必ず一意に決まる

### 意図した性質（テストで確認済み）
- 分野がそろっている人（最大9点）は、AI未経験でもその分野になる（準備度のE点は最大8点）
- 完全な初心者で、分野の答えが4問そろわない人は E（まず1作型）
- 経験者は、「まだ決まっていない」系を選ばない限り E にならない
- 準備度のE点が4以上でE以外の結果になった人には「ゆっくりペースでOK（1日15分）」の案内を表示
- どのタイプの「最初の1作」も、HTML1ファイル・サーバーなし・機能4〜6個に抑え、初心者でも作れる規模にした

### 判定理由の表示
選ばれたタイプに点が入った回答（点の大きい順に最大3つ）を「◯◯と答えた」と表示し、5タイプの点数バーと、同点処理を使った場合はその説明を出す。

## 4. 結果原稿
`shindan/diagnosis.js` の `TYPES` を正とする。各タイプに：タイプ名・キャッチコピー・要約・最初に作るツール1つ・完成形のイメージ（文章＋画面の模型）・必須機能・Day 1〜7（作業と完了の目安）・AIへの制作指示（共通条件付き）・つまずき3つと対処・作例（実在するものだけ）。

## 5. OSS の採否
| 候補 | 判断 | 理由 |
|---|---|---|
| Tailwind CSS (MIT) | 不採用 | ビルド環境が必要。CDN版は本番非推奨。既存サイトも素のCSS |
| Sharer.js (MIT) | 不採用 | X・Threads は共有用URLへのリンク2本で足りる。読み込みを増やさない |
| Heroicons / Feather (MIT) | 不採用 | アイコンは3つだけで、自作の簡単なSVGで足りる（ライセンス表示も不要に） |
| Quizzo (GPL-3.0) | 不採用 | GPLの波及と保守状況 |
| SurveyJS | 不採用 | 機能過多・重い |
| 静的サイトジェネレータ | 不採用 | 既存サイトがビルドなしのため |
| axe-core (MPL-2.0) | **テストのみ使用** | アクセシビリティ自動検査。公開ページには含めない |
| Playwright (Apache-2.0) | **テストのみ使用** | 既存テストと同じ |

公開ページが読み込む外部ライブラリは0件のため、ライセンス表示義務は発生しない。

## 6. プライバシー・技術
- 外部通信なし。CSP（`connect-src 'none'` ほか）で送信系の通信をブラウザ側でも禁止
- 回答は保存しない（ページを閉じると消える）。localStorage も使わない
- 外部サイトが開くのは LINE・X・Threads のボタンを押したときだけ。共有文にはタイプ名とツール名だけを入れ、回答そのものは入れない
- 合計約73KB（gzip後 約24KB）。フォント・画像の外部読み込みなし

## 7. LINE導線とKPI
- 主目標：**診断経由のLINE友だち追加 10件**（1件増加は成功扱いにしない）
- 取れる指標と取れない指標
  - LINEボタンのクリック数：**現状取れない**（計測なし）
  - 診断経由の友だち追加数：診断専用の友だち追加URL `https://lin.ee/wvWY1Xo` に差し替え済み（`shindan/app.js` の `LINE_URL`）。LINE公式アカウント側の数字で確認する
  - 友だち追加の総数：LINE公式アカウントの管理画面で確認できる（ただし診断以外の経路も含む）
- 文言は既存の事実（無料サンプルの設計図をLINEで渡している）のみ。「タイプ別メモ配布中」は特典が完成するまで書かない
